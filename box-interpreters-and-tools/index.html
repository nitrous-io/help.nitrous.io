Included Interpreters and Tools

Last Updated on: 25 November 2013

We provide extra interpreters and tools in your Nitrous boxes to help you get hacking away instantly.

Here is a list of the tools we provide as well as some examples of other tools you could install yourself (without needing root access):

Tools Available on All Nitrous Boxes

Development Tools

  • C
  • C++
  • JVM
  • Perl
  • PhantomJS
  • Python (isolated environments with virtualenv only on Python box)
  • Ruby (version control with RVM only available on Ruby box)
  • Golang
  • automake
  • Heroku Toolbelt
  • Parse Command Line Tool

Available in Autoparts

Autoparts is a open source package manager which allows you to install databases and tools within a single command. Here is a list of the

  • Composer
  • PHP5
  • Erlang
  • Go
  • Google App Engine
  • Leiningen
  • Lua
  • Maven
  • Memcached
  • Meteor
  • MongoDB
  • MySQL
  • Node.JS
  • Phantom.JS
  • PHPMyAdmin
  • Pip
  • Python2/3
  • Redis
  • Scala
  • Tmux
  • Zsh

For a full list of parts, run parts search within the console of your Nitrous box.
