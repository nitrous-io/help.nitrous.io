Backing up your Nitrous Lite data is simple, since standards such as SSH and SFTP are supported.

Do note that due to the way `autoparts` works, if you have data stored in an autoparts database (e.g. `postgres`,
`mongodb`, etc), it will not be straightforward to access it outside of the Nitrous Lite environment.  You will be
better served by [migrating to Nitrous Pro](http://docs.nitrous.io/v1.0/docs/migrate-your-box-to-nitrous-pro).

If you haven't already done so, you will first need to add your public key to Nitrous in order to access your box.

The guides for doing this can be found [here](/ssh-add) (Mac) or [here](/ssh-windows) (Windows).

![Box Details](https://raw.github.com/action-io/action-assets/master/support/screenshots/box-details.png)

The `SSH URI` field contains what we need to access the box.  So using the above screenshot, these are the
three pieces of information needed:

- username: `action`
- hostname: `apse1.actionbox.io`
- port: `12768`

We will now describe two options for backing up your data.

### Backing up via rsync

We recommend this approach.  Linux and Mac users should have easy access to `rsync`.  Windows users with
[Cygwin](https://www.cygwin.com/) can use `rsync` from that environment, or skip ahead to the `Backing up via FileZilla`
section if `rsync` is not a viable option.

The command to run is:

`rsync -av --partial --progress -e 'ssh -p <port>' action@<hostname>:/home/action /path/to/destination`

Note that you should replace `<port>` and `<hostname>` with the values from your box's `SSH URI` field, and replace
`/path/to/destination` with the location you want your backup to be.

The `--progress` flag will list the files in your terminal as they are copied.  Once the command completes without any
errors, your backup is complete!

### Backing up via Filezilla

Since Filezilla is cross-platform, this option is available to users of Linux, Mac, or Windows.

First, install the [Filezilla client](https://filezilla-project.org/).

Next, add your private key to Filezilla.  Follow the instructions in the "SFTP via SSH2 Key-based Authentication"
section in this
[tutorial](https://www.digitalocean.com/community/tutorials/how-to-use-filezilla-to-transfer-and-manage-files-securely-on-your-vps).

In the site manager dialog, populate the fields as follows:

- Host: `hostname` from SSH URI
- Port: `port` from SSH URI
- Logon Type: `interactive`
- User: `action`

By choosing the `interactive` logon type, you will not have to fill in a password.

When you click `Connect`, you will see a split-pane view.  The left pane is `Local site` and contains a file tree of
your local machine.  The right pane is `Remote site` and contains a file tree of your Nitrous Lite box.  You can then
select the files and directories there and copy them over to a location of your choice on your machine.
